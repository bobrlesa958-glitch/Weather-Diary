# Weather Diary – Дневник погоды

**Автор:** Светлана Гренко
## Описание

Графическое приложение для ведения дневника погоды. Позволяет:
- Добавлять записи с датой, температурой, описанием и отметкой об осадках.
- Просматривать все записи в удобной таблице.
- Фильтровать записи по конкретной дате или по минимальной температуре.
- Сохранять и загружать данные в формате JSON.
- Проверять корректность ввода (формат даты, числовое значение температуры, непустое описание).

## Запуск

Убедитесь, что установлен Python 3.6+. Запустите из командной строки:

```bash
python weather_diary.py
